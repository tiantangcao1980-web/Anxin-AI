# Legacy Mini Program Client

> Status: legacy during the uni-app migration.

This Taro WeChat Mini Program remains as the reference implementation for `wx.login -> code2session`, no-mock-token auth, navigation guards, privacy-mode request blocking, and design-token checks.

New mini-program feature work should target the planned `apps/uni-mobile/` uni-app client. Changes in this directory should be limited to security fixes, regression preservation, and migration extraction until the uni-app replacement reaches equivalent evidence.

Migration plan: `../docs/mobile/uni-app-migration-plan.md`
