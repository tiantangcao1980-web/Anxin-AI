# Legacy Mobile Client

> Status: legacy during the uni-app migration.

This Expo/React Native client remains as the reference implementation for existing mobile API calls, privacy-mode guards, desktop-control safe-probe flow, and regression tests.

New mobile and mini-program feature work should target the planned `apps/uni-mobile/` uni-app client. Changes in this directory should be limited to security fixes, regression preservation, and migration extraction until the uni-app replacement reaches equivalent evidence.

Migration plan: `../docs/mobile/uni-app-migration-plan.md`
