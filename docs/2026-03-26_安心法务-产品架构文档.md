## 1. 产品概览

### 1.1 产品定义

| 项目 | 说明 |
|------|------|
| **产品名称** | 安心法务 |
| **英文名称** | Anxin Smart Legal Services |
| **品牌含义** | "安心"寓意守护、放心、专业 —— 让每一位用户在法律事务中感到安心 |
| **产品定位** | 通过 AI 能力 + 一键触达律师，协助律师、中小企业和个人解决法律合规问题 |
| **技术定位** | 基于多智能体协作的超级 AI 法务系统 |

### 1.2 核心价值主张

```
┌─────────────────────────────────────────────────────────────────┐
│                      安心法务 · 核心价值                         │
├───────────────┬───────────────┬───────────────┬─────────────────┤
│  AI 法律咨询  │ 匿名找律师    │ 合同全生命周期 │  企业合规管理   │
│  智能对话问答  │ 滴滴模式匹配  │ 审查→签约→归档 │  风险监测预警   │
│  多智能体协作  │ 4级信息揭示   │ 智能条款分析   │  合规自检报告   │
├───────────────┴───────────────┴───────────────┴─────────────────┤
│                       私有化部署能力                             │
│            支持企业内网部署，数据完全自主可控                      │
└─────────────────────────────────────────────────────────────────┘
```

### 1.3 产品差异化

| 差异点 | 安心法务 | 传统法律SaaS |
|--------|---------|-------------|
| AI 能力 | 多智能体协作（13+ 专业Agent） | 无或单一问答 |
| 找律师模式 | 滴滴式匿名匹配 + 渐进揭示 | 目录式浏览 |
| 合同管理 | AI 审查 + 全生命周期管理 | 模板填写 |
| 知识图谱 | 3D 可视化法律关系网络 | 关键词搜索 |
| 部署方式 | 公有云 + 私有化 | 仅公有云 |
| 协作能力 | 实时多人协同编辑（基于 Yjs） | 文件共享 |

### 3.3 规划中功能

#### 3.3.1 找律师（滴滴模式）

```
用户发布需求 → AI 分析匹配 → 律师抢单/派单 → 渐进揭示 → 委托签约 → 支付 → 专属协作群
      │                                          │
      │              4 级信息揭示机制              │
      │  ┌──────────┬──────────┬──────────┬──────┤
      │  │ L1 匿名   │ L2 基本   │ L3 详细   │ L4 │
      │  │ 仅需求摘要│ 行业+地区 │ 联系方式  │完整 │
      │  │ 双方匿名  │ 律师可见  │ 双向可见  │信息 │
      └──┴──────────┴──────────┴──────────┴──────┘
```

**核心流程**:

1. 用户以匿名方式发布法律需求
2. AI 根据需求类型、地域、专业领域智能匹配律师
3. 符合条件的律师收到脱敏需求摘要，可选择接单
4. 双方通过 4 级渐进揭示逐步建立信任
5. 达成意向后一键委托 + 在线签约 + 支付
6. 自动创建专属协作群，进入案件管理流程

#### 3.3.2 获客系统

| 端 | 功能 | 说明 |
|----|------|------|
| **律师端** | 专业主页、案例展示、服务定价、接单管理 | 律师自主运营个人品牌 |
| **用户端** | 需求发布、智能推荐、评价体系、争议处理 | 透明化法律服务市场 |

#### 3.3.3 律所内部管理

- 团队工作量看板
- 绩效统计与分析
- 案件分配与调度
- 财务管理（创收、回款、成本）
- 客户关系管理（CRM）

#### 3.3.4 私有化部署

- 企业内网独立部署
- 数据完全自主可控
- 自定义 AI 模型（支持接入私有大模型）
- 定制化品牌与功能

#### 3.3.5 AI 私有助手（OpenClaw 集成）

- 基于 OpenClaw 开源框架的本地私有化 AI 服务
- 首次安装提供引导程序（环境检测 → 下载 → 配置 → 验证）
- 法律 NLP 模型本地部署
- 判例智能分析增强
- 数据完全自主可控，支持离线运行
