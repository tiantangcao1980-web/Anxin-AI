# 移动端错误态发布说明草案

> 日期：2026-05-07
> 状态：draft，需在 iOS/Android/微信开发者工具真机验收后合并进正式 release notes。

## 用户可见变化

- 移动端消息、任务、审批、案件等详情页不再用示例内容或假数据掩盖加载失败。
- 小程序首页资讯加载失败或暂无内容时，会显示明确空态，不再展示假新闻。
- 小程序登录链路使用 `wx.login -> code2session -> JWT`，不再写入体验模式 token。

## 需要客服/运营知道的口径

- 用户看到错误页或空态时，表示后端、网络、权限或数据确实不可用，不代表 App 自动降级成功。
- 401 表示登录过期，需要重新登录。
- 403 表示当前账号无权限。
- 404 表示内容不存在或已删除。
- 网络失败会提供重试入口。

## 发布前必须补齐

- iOS 真机登录、详情页、网络失败重试截图或录屏。
- Android 真机登录、详情页、网络失败重试截图或录屏。
- 微信开发者工具或真机的 `wx.login -> code2session -> JWT` transcript。
- 跨设备会话延续：桌面开始会话，移动端继续查看 `last_message` / draft / unread。
- 按 `docs/design/cross-platform-token-drift.md` 处理 P0 设计漂移，或在发布说明中明确保留平台差异。
