## 演示话术要点

### 核心卖点
1. **多 persona 专家系统**：不是单一 AI，而是 10 个垂直专家
2. **全端覆盖**：Web + 桌面 + 小程序 + H5，用户在哪里我们就在哪里
3. **商业闭环**：订阅 + 支付 + 电子签章，完整的 SaaS 商业模式
4. **私有化部署**：支持企业级私有化（NAS / 云服务器 / 本地机房）

### 技术亮点

- **知识库**：向量数据库 + 知识图谱（RAG 增强）

### 市场定位
- **目标客户**：中小企业（50-500 人）、律所、财税机构
- **竞品对比**：华宇信息（传统重）、幂律智能（律所专用）、法狗狗（功能单一）
- **差异化**：多 persona + 全端 + 私有化

## 常见问题 Q&A

**Q1：AI 回复的准确性如何保证？**
> A：我们采用 RAG（检索增强生成）技术，AI 回复基于权威法律法规库 + 案例库，并引用具体法条。同时支持人工审核和反馈机制。

**Q2：数据安全如何保障？**
> A：支持私有化部署，数据不出企业内网。同时提供数据加密、权限控制、审计日志等安全措施。

**Q3：如何与现有系统集成？**
> A：提供 REST API + Webhook，支持与 OA、CRM、ERP 等系统集成。

**Q4：定价策略是什么？**
> A：基础版 99 元/月（个人用户），专业版 499 元/月（中小企业），企业版按需定制（大客户）。

**Q5：未来规划？**
> A：Q3 上线知识图谱（法律关系推理），Q4 上线语音助手（电话法律咨询），2027 年拓展海外市场。
