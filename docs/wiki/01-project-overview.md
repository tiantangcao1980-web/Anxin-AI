# 项目总览

## 产品定位

安心法务是一个 AI 智能法务平台，目标用户包括个人、中小企业、律师和律所。产品希望把 AI 法律咨询、合同审查、文档协作、法律知识库、尽职调查、找律师、案源市场和后台运营能力整合成一套多端系统。

## 当前产品形态

项目已经不是单页 demo，而是一个多端 monorepo：

| 区域 | 目录 | 说明 |
|---|---|---|
| Web 前端 | `frontend/` | React 18 + Vite + TypeScript，用户端、律师 Pro 端和后台管理共用 |
| 后端 | `backend/` | FastAPI + SQLAlchemy，覆盖认证、合同、文档、订阅、支付、电签、IM、知识库等 |
| 桌面端 | `desktop/` | Tauri 2.x，复用 Web 前端并提供本地能力 |
| 移动端 | `mobile/` | Expo / React Native，独立轻量移动工作台 |
| 微信小程序 | `mini-program/` | Taro 小程序/H5，轻量入口 |
| 文档 | `docs/` | 架构、审计、发布、桌面同步、交付规格等文档 |
| 技能 | `skills/` | 法律/金融领域 agent skill |

## 真实状态摘要

完成度最高的是 Web 主产品和后端主线。合同审查、文档、知识库、认证、权限、订阅门控、部分支付渠道 provider、IM、后台管理等都有真实实现和测试覆盖。

需要谨慎看待的是“外部渠道完成度”。支付、电签、OA、多模态 OCR/ASR、移动端调查/知识库搜索、桌面同步等仍有 mock、占位或未完全接通的地方。

因此，当前适合：

- 内部验收
- 演示主线业务流
- 试点客户预发布
- 继续做生产化收口

当前不适合直接宣称：

- 全平台正式 1.0 完成
- 支付/电签真实商业闭环已完成
- 桌面离线同步已可信闭环
- 移动端与 Web 等功能
